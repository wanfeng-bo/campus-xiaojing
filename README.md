# 校园小静：学校事实与受控 AI 助手

面向教职工、家长和学校资料维护者。用户用大白话提问，模型理解和选择工具，后台核对身份、权限、时间与事实；正式修改需要预览、明确确认、唯一Writer执行和真实回执。

**这是已停止继续开发的源码交付，不是开箱即用的学校SaaS。** 学校事实F1—F8已有实现和原项目分阶段验收；真实学校全面入驻及正式模型上线没有完成。已有查询时延和表达限制如实保留。

学校目录、人员组织、地点联系制度、家校关系、班级与班主任、持续教学、寄宿事实、质量覆盖和维护能力共用正式授权读写路径。课程事实不等于排课、成绩或课堂教学；寄宿事实不等于已经建成宿管业务；历史报修包未因为仍在源码中而自动上线。

使用者自备数据库、缓存、钉钉应用和DeepSeek密钥及额度。**没有作者共享密钥、赠送额度或代调用服务。** 默认不得因安装就产生模型费用；必须先完成自己的配置与数据政策核对。
