# 使用自己的 DeepSeek 密钥和额度

本项目不提供共享API、不含作者密钥，也不连接作者的费用账本。模型配置由部署者自己的后台读取；前端只能请求自己部署的Product。

## 实际接续位置

正式入口：`app.composition.school_fact_live_product:create_app`，配置由`SCHOOL_FACT_PRODUCT_CONFIG`指向受保护的绝对JSON文件。`LiveSchoolFactProductConfiguration`在`apps/api/app/composition/school_fact_live_settings.py`定义全部字段。

模型字段`model.api_key_file`是后端私有文件的绝对路径；文件内仅放自己的密钥。不要把密钥填在`model`字段、网页输入框或任何`VITE_`变量。`model.state_directory`保存本实例独立的用量/占款元数据，不与示例或原项目共用。

`assistant_enabled:false`允许在模型尚未配置时只启用获准资料功能；正式启用还要求模型、预算窗口和数据政策引用均成立。不开启时界面不显示聊天框，这不是安装失败。

当前源码正式合同固定`deepseek-flash`、思考开启/high、30天100元上限并核对输入/输出计价（源码为3/9元每百万计量单位）。这描述现有实现，不是对供应商当前价格的声明，也不是承诺通用可调预算。任何部署均先核对实际可用型号/单价/数据政策；不匹配时保持停用，不擅自关闭校验。

## 必须先完成

1. 为自己的学校建立独立数据库、Reader/Writer和受信任身份；真实钉钉应用、合法初始化操作者及资料范围由部署者提供。
2. 在自己的服务器保存密钥，配置自己的固定预算窗口、持久账本位置及明确的模型数据范围。
3. 先用合成资料核对授权读取和确认回执，再启用有限真实模型请求。学校资料没有录入时应诚实无记录，不植入固定答案。
4. 监测自己供应商账单与本地用量估计的差异；未知占款不清零，超额停止，不自动充值。

聊天最多24小时内存、服务重启可提前丢失；不持久化完整提示/回答/思考。供应商留存取决于你实际购买服务的适用条款，本项目不保证供应商零留存。

本次发布没有提供通用一键建校或密钥设置页面；已有私有初始化记录也不会随开源提供。完整配置与真实学校身份接入需要有后台部署能力的人负责。
